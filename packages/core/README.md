# @chayuto/solitaire-core

Core game logic library for Solitaire (Klondike).

## Overview

This package provides the core game logic, rules, and utilities for implementing Solitaire card games.

## Installation

```bash
npm install @chayuto/solitaire-core
```

## Structure

- `types/` - Type definitions
- `engine/` - Game engine implementation
- `rules/` - Game rules and validation
- `utils/` - Utility functions
- `scoring/` - Scoring system

## Development

```bash
# Build the library
npm run build

# Run tests
npm run test

# Type check
npm run typecheck
```
