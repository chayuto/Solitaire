# Recommendation: Maintain AGENTS.md

**Date:** 2025-02-18
**Status:** Implemented

## Context
AI agents require context to operate effectively within a codebase. While a human developer might intuit project structure or conventions over time, an agent needs explicit, structured instructions available immediately upon entering the environment.

## Proposal
Create and maintain an `AGENTS.md` file in the root of the repository. This file should act as the "handbook" for any AI agent working on the project.

## Content Requirements
The `AGENTS.md` file should include:
1.  **Project Map**: A high-level overview of the directory structure and the purpose of each major component (monorepo packages).
2.  **Command Reference**: The exact commands to build, test, lint, and run the project, including dependency ordering (e.g., "build libs before app").
3.  **Coding Standards**: Explicit rules for TypeScript usage, React patterns, and state management.
4.  **Workflow**: A recommended step-by-step process for making changes (Explore -> Plan -> Edit -> Verify).
5.  **Contextual Nuances**: Information about "gotchas" or specific architectural decisions that aren't obvious from the code itself.

## Benefits
- **Reduced Hallucination**: Agents are less likely to invent non-existent scripts or follow wrong patterns.
- **Faster Onboarding**: Agents can immediately understand the build pipeline.
- **Consistency**: All agents (and human contributors) have a single source of truth for "how we do things here."

## Implementation Steps
1.  Create `AGENTS.md` in the root.
2.  Populate it with current project details.
3.  **Crucial**: Update this file whenever the build process or architecture changes.
